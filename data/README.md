Download or generate each file below before running the pipeline.

## PPI graph — SHS27k benchmark

| File | Description |
|---|---|
| `ppi_SHS27k.tsv` | STRING protein-protein interaction graph (SHS27k subset) |
| `shs27k_ensps.txt` | List of ENSP IDs in the SHS27k graph |
| `protein_seq_SHS27k.tsv` | Amino-acid sequences for SHS27k proteins |

**Source**: [Mashaghi et al. / STRING DB SHS27k benchmark](https://string-db.org/)  
Download the SHS27k TSV from the STRING database and place it here.

## Pathway source data

Built by the enrichment pipeline scripts (downloaded from public APIs):

```
pathway/
├── 01_gene_to_pathway_ids.json      KEGG: Entrez gene → pathway IDs
├── 02_pathway_id_to_name.json       KEGG: pathway ID → name
├── 03_pathway_id_to_genes.json      KEGG: pathway ID → gene list
├── 04_pathway_to_description.json   KEGG: pathway ID → biology paragraph
├── 05_gene_to_descriptions.json     KEGG: per-gene description list
├── reactome/
│   ├── R1_gene_to_pathways.json     Reactome: ENSG → [[id, name], ...]
│   └── R2_summations/               one .json per Reactome pathway
└── wikipathways/
    └── wikipathways_human.gmt       WikiPathways GMT file
```

Run the following once to populate:

```bash
python -m scripts.enrichment.pathway_embed       # KEGG
python -m scripts.enrichment.reactome_embed      # Reactome
python -m scripts.enrichment.wikipathways_embed  # WikiPathways
```

## RAG index

Built from the pathway source data above:

```
rag/
├── docs.jsonl              pathway documents (one per line)
├── embeddings.npy          BioBERT vectors aligned to docs.jsonl
├── gene_to_doc_ids.json    reverse index: gene_id → [doc_id, ...]
├── id_map.json             row index → doc_id
└── build_log.json          build metadata
```

Run once after building pathway data:

```bash
python -m scripts.rag.build_index
```
