## Pathway source data

Built by the enrichment pipeline scripts (downloaded from public APIs):

```
pathway/
├── 01_gene_to_pathway_ids.json      KEGG: Entrez gene → pathway IDs
├── 02_pathway_id_to_name.json       KEGG: pathway ID → name
├── 03_pathway_id_to_genes.json      KEGG: pathway ID → gene list
├── 04_pathway_to_description.json   KEGG: pathway ID → biology paragraph
├── 05_gene_to_descriptions.json     KEGG: per-gene description list
├── reactome/
│   ├── R1_gene_to_pathways.json     Reactome: ENSG → [[id, name], ...]
│   └── R2_summations/               one .json per Reactome pathway
└── wikipathways/
    └── wikipathways_human.gmt       WikiPathways GMT file
```

Run the following once to populate:

```bash
python -m scripts.enrichment.pathway_embed       # KEGG
python -m scripts.enrichment.reactome_embed      # Reactome
python -m scripts.enrichment.wikipathways_embed  # WikiPathways
```

```
rag/

```

Run once after building pathway data:

```bash

```

## Reference genome (required for bulk RNA-seq alignment)

The STAR aligner needs a pre-built genome index.  Building it requires:

| File | Size | Source |
|---|---|---|
| `GRCh38.primary_assembly.genome.fa.gz` | ~900 MB | [GENCODE](https://www.gencodegenes.org/human/) |
| `gencode.v47.annotation.gtf.gz` | ~50 MB | [GENCODE](https://www.gencodegenes.org/human/) |

### Step 1 — download

```bash
mkdir -p data/genome && cd data/genome

# Reference genome FASTA
wget https://ftp.ebi.ac.uk/pub/databases/gencode/Gencode_human/release_47/GRCh38.primary_assembly.genome.fa.gz
gunzip GRCh38.primary_assembly.genome.fa.gz

# GTF annotation
wget https://ftp.ebi.ac.uk/pub/databases/gencode/Gencode_human/release_47/gencode.v47.annotation.gtf.gz
gunzip gencode.v47.annotation.gtf.gz
```

### Step 2 — build STAR index (~30–60 min, ~30 GB output)

```bash
mkdir -p data/star_index

STAR \
  --runMode genomeGenerate \
  --genomeDir data/star_index \
  --genomeFastaFiles data/genome/GRCh38.primary_assembly.genome.fa \
  --sjdbGTFfile data/genome/gencode.v47.annotation.gtf \
  --runThreadN 8
```

### Step 3 — point the pipeline at it

When `collect_config_from_user()` prompts for:
- **GTF path** → `data/genome/gencode.v47.annotation.gtf`
- **Genome dir** → `data/star_index`

Or pass programmatically:

```python
cfg = PreprocessingConfig(
    genome_dir = Path("data/star_index"),
    gtf        = Path("data/genome/gencode.v47.annotation.gtf"),
    ...
)
```

> **Note**: the genome and STAR index directories are gitignored (`data/genome/`, `data/star_index/`).
